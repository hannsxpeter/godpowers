# /god-status

1. Run `npx -y godpowers@7 status`.
2. Relay it in a few lines: the stage, whether the current code has a passing check, review, and security record, open risks by severity, and the next step.
3. If it reports a problem (6.x layout, lint errors, missing hooks), name the one command that fixes each. Change nothing.
